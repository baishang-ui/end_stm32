# 现有外设专用扩展板方案

## 1. 设计范围

这块扩展板只服务于当前项目已经在用的外设，不新增新的功能模块，不引入新的总线规划。

只包含这些内容：

- SPI OLED 显示屏
- 旋钮编码器
- 旋钮按键
- 4 个快捷键
- ESP-01S Wi-Fi 模块
- DHT11 温湿度接口
- 状态 LED
- 主板供电与连接器

## 2. 当前主板已用资源

### 2.1 显示

- `PA5` -> `SPI1_SCK`
- `PA7` -> `SPI1_MOSI`
- `PA4` -> `OLED_CS`
- `PB0` -> `OLED_DC`
- `PB1` -> `OLED_RST`

### 2.2 交互输入

- `PB12` -> 编码器 A
- `PB13` -> 编码器 B
- `PB14` -> 编码器按键
- `PC0` -> 快捷键 1
- `PC1` -> 快捷键 2
- `PC2` -> 快捷键 3
- `PC3` -> 快捷键 4

### 2.3 联网

- `PA2` -> `USART2_TX` -> ESP-01S `RXD`
- `PA3` -> `USART2_RX` -> ESP-01S `TXD`

### 2.4 传感器

- `PB15` -> DHT11 数据

### 2.5 指示

- `PB2` -> 状态 LED

### 2.6 USB

- `PA11` -> USB `DM`
- `PA12` -> USB `DP`

说明：

- USB 差分线不建议通过扩展板长距离绕行，最好仍然走主板原接口。
- `PA4` 当前已经被 OLED 和板级 `spi1` 设备挂载逻辑共同占用，因此不再把 SPI1 作为额外扩展总线使用。

## 3. 扩展板定位

这块板建议做成“前面板式交互扩展板”，核心目标不是扩展更多功能，而是把当前所有外设集中到一块板上，解决：

- 接线杂乱
- 飞线不稳定
- 结构装配困难
- 按键和旋钮布局不统一
- ESP 和 OLED 供电去耦不足

## 4. 扩展板模块划分

### 4.1 OLED 显示区

直接放一块和当前固件兼容的 SPI OLED。

接口定义：

- `SCK` -> `PA5`
- `MOSI` -> `PA7`
- `CS` -> `PA4`
- `DC` -> `PB0`
- `RST` -> `PB1`
- `VCC` -> `3.3V`
- `GND`

建议：

- OLED 旁边加 `0.1uF + 4.7uF` 去耦
- `SCK/MOSI` 可预留 `22R` 串联电阻焊位

### 4.2 旋钮区

放 1 个带按压的机械编码器。

接口定义：

- `A` -> `PB12`
- `B` -> `PB13`
- `SW` -> `PB14`
- `GND`

建议：

- 编码器尽量靠近面板中心
- 每路信号可预留 `100nF` 抗抖焊位

### 4.3 快捷键区

放 4 个独立按键。

接口定义：

- `K1` -> `PC0`
- `K2` -> `PC1`
- `K3` -> `PC2`
- `K4` -> `PC3`

连接方式：

- 按键一端接 GPIO
- 另一端接 `GND`
- 使用软件内部上拉

建议布局：

- 4 键横排或 2x2 布局
- 靠近旋钮区域，便于单手操作

### 4.4 ESP-01S 区

放 1 个 `ESP-01S` 8Pin 插座。

接口定义：

- `RXD` <- `PA2`
- `TXD` -> `PA3`
- `VCC` -> `3.3V`
- `GND`
- `EN` -> `3.3V` 上拉
- `RST` -> `3.3V` 上拉
- `GPIO0` -> `3.3V` 上拉
- `GPIO2` -> `3.3V` 上拉

建议：

- `EN/RST/GPIO0/GPIO2` 各自预留 `10k` 上拉
- 模块旁边增加 `470uF + 10uF + 0.1uF`
- 天线区域禁止铺铜和高线密度走线

### 4.5 DHT11 区

只保留当前 DHT11 接口，不扩成通用传感器总线。

接口定义：

- `DATA` -> `PB15`
- `VCC` -> `3.3V`
- `GND`

建议：

- 预留 `4.7k` 数据上拉
- 如果传感器不板载，可做成 3Pin 插座

### 4.6 状态 LED 区

放 1 个单色 LED。

接口定义：

- `PB2` -> 串联限流电阻 -> LED -> 电源或地

按当前固件习惯，建议保持和现有板一致的点亮逻辑。

## 6. 电源设计

这版只服务现有外设，电源设计保持简单。

### 6.1 输入

- 从主板取 `5V`
- 从主板取 `3.3V`

### 6.2 供电对象

- `3.3V`：
  - OLED
  - ESP-01S
  - DHT11
- `5V`：
  - 只做直通备用，不强制使用

### 6.3 去耦建议

- OLED 附近：`0.1uF + 4.7uF`
- ESP 附近：`470uF + 10uF + 0.1uF`
- DHT11 附近：`0.1uF`

## 7. 布局建议

建议做成一块偏“操作面板”的板子。

### 推荐布局

- 上方：OLED
- 中间：旋钮
- 旋钮两侧或下方：4 个快捷键
- 一侧边缘：ESP-01S
- 另一侧边缘：DHT11 接口
- 底部：主连接器

### 布线重点

- OLED SPI 线尽量短
- 编码器线靠近主控连接器，减少干扰
- ESP 天线外侧留空
- 电源地尽量完整铺铜

## 8. 最终建议版本

如果只基于现有外设，我建议直接做这一版：

- 1 个 SPI OLED
- 1 个旋钮编码器
- 4 个独立按键
- 1 个 ESP-01S 插座
- 1 个 DHT11 接口
- 1 个状态 LED
- 1 个 `2x10` 主板连接器

这版的优点是：

- 与现有固件完全对应
- 不需要新增功能驱动
- 原理图简单
- PCB 风险低
- 调试成本最低
