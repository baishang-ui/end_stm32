# STM32F407 主板扩展板方案

## 1. 目标

基于当前 `STM32F407VET6` 主板和现有固件功能，设计一块可直接配套使用的扩展板，满足以下目标：

- 保留现有功能：
  - USB HID 电脑控制
  - OLED 显示
  - 旋钮输入
  - 4 个快捷键
  - ESP-01S 联网
  - DHT11 温湿度采集
- 提供更规范的外设连接方式，减少飞线
- 预留后续扩展能力，避免与当前已占用接口冲突
- 便于后续直接画原理图和 PCB

## 2. 当前主板已占用资源

### 2.1 已明确占用的接口

- `SPI1`
  - `PA5` -> `SPI1_SCK`
  - `PA7` -> `SPI1_MOSI`
  - `PA4` -> `SPI1_CS`
  - 当前既被 OLED 使用，也被板级 `spi1` Flash 设备挂载逻辑占用
- `USART2`
  - `PA2` -> ESP-01S `RX`
  - `PA3` -> ESP-01S `TX`
- `USB FS`
  - `PA11` -> USB `DM`
  - `PA12` -> USB `DP`
- `OLED 控制`
  - `PA4` -> `OLED_CS`
  - `PB0` -> `OLED_DC`
  - `PB1` -> `OLED_RST`
- `旋钮`
  - `PB12` -> 编码器 A
  - `PB13` -> 编码器 B
  - `PB14` -> 编码器按键
- `DHT11`
  - `PB15` -> 数据脚
- `4 个快捷键`
  - `PC0` ~ `PC3`
- `状态 LED`
  - `PB2`

### 2.2 CubeMX 已配置但当前不建议复用的接口

- `USART1`
  - `PA9` / `PA10`
- `SDIO`
  - `PC8` ~ `PC12`
  - `PD2`
- `PD3`
  - 目前板级已有其他用途，不建议直接拿来做扩展板主接口

## 3. 扩展板总体结构

建议做成一块“功能型扩展底板”，通过排针或板对板连接器与主板相连，扩展板自身不放主控，主要承担：

- 外设集中连接
- 电源分配和保护
- 标准接口引出
- 人机交互模块集成
- 未来传感器/执行器扩展

建议划分为 6 个功能区：

1. 电源与保护区
2. USB/主板连接区
3. 人机交互区
4. 网络与环境采集区
5. 通用扩展接口区
6. 执行器输出区

## 4. 推荐扩展板功能

### 4.1 保留并规范化的现有模块

#### A. OLED 显示区

- 直接在扩展板上放 `0.96/1.3 寸 SPI OLED` 焊盘或插座
- 使用当前已兼容的接口：
  - `PA5` -> `SCK`
  - `PA7` -> `MOSI`
  - `PA4` -> `CS`
  - `PB0` -> `DC`
  - `PB1` -> `RST`
- 建议在 OLED 供电脚附近增加：
  - `0.1uF + 4.7uF` 去耦
  - 串联 `22~33R` 时钟阻尼电阻可选位

#### B. 旋钮输入区

- 板上放一个带按压编码器
- 引脚：
  - `PB12` -> A
  - `PB13` -> B
  - `PB14` -> 按键
- 增加硬件抗抖：
  - 每路可预留 `100nF` 到地焊位
  - 0R/空贴兼容，便于实测调整

#### C. 快捷键区

- 板上放 4 个独立按键
- 引脚：
  - `PC0`
  - `PC1`
  - `PC2`
  - `PC3`
- 建议采用：
  - 一端接 IO
  - 一端接 GND
  - 软件内部上拉
- 可增加丝印：
  - `K1`
  - `K2`
  - `K3`
  - `K4`

#### D. ESP-01S 插座区

- 扩展板放 `ESP-01S` 8Pin 母座
- 引脚：
  - `PA2` -> ESP `RXD`
  - `PA3` -> ESP `TXD`
- 配套电路：
  - `3.3V` 独立 LDO 或主 3.3V 大电流供电
  - `EN` 上拉
  - `RST` 上拉并预留复位按键
  - `GPIO0/GPIO2` 上拉
- 重点：
  - ESP 峰值电流较高，建议单独预留 `470uF + 10uF + 0.1uF`

#### E. DHT11 传感器接口

- 预留 3Pin 传感器座：
  - `PB15`
  - `3.3V`
  - `GND`
- 如果走线较长，建议：
  - 数据线上预留 `4.7k` 上拉
  - 串 `33~100R` 阻尼

### 4.2 建议新增的扩展功能

#### A. 蜂鸣器

- 推荐使用一个 `NPN/MOS` 驱动的无源蜂鸣器
- 建议使用一个空闲 GPIO 或 PWM 引脚接入
- 优先建议新引出空闲资源到扩展板再分配，不直接抢当前业务引脚

#### B. RGB 状态灯

- 可加 1 颗 `WS2812B`
- 作用：
  - 网络状态
  - USB 状态
  - 同步状态
  - 启动动画

#### C. I2C 扩展口

- 建议在扩展板上新增一组标准 `I2C` 接口
- 用于未来接：
  - SHT30
  - BH1750
  - RTC
  - EEPROM
  - IO 扩展芯片
- 这部分建议使用主控当前未占用引脚重新分配，例如：
  - `PB8` -> `SCL`
  - `PB9` -> `SDA`
- 需要同步更新固件和 CubeMX

#### D. ADC 扩展口

- 建议至少预留 2 路模拟输入
- 用于：
  - 光敏电阻
  - 电位器
  - 电池电压检测

#### E. 执行器输出口

- 预留 2 路晶体管驱动输出
- 可接：
  - 小继电器
  - 风扇
  - 灯带 MOS 驱动

## 5. 推荐连接器定义

建议主板与扩展板之间使用 `2x10` 或 `2x12` 排针。

### 5.1 主连接器建议

#### J1: 主板连接器

1. `5V`
2. `3.3V`
3. `GND`
4. `GND`
5. `PA5`  `SPI1_SCK`
6. `PA7`  `SPI1_MOSI`
7. `PA4`  `OLED_CS / SPI1_CS`
8. `PB0`  `OLED_DC`
9. `PB1`  `OLED_RST`
10. `PB12` `ENC_A`
11. `PB13` `ENC_B`
12. `PB14` `ENC_KEY`
13. `PC0`  `KEY1`
14. `PC1`  `KEY2`
15. `PC2`  `KEY3`
16. `PC3`  `KEY4`
17. `PA2`  `ESP_TX`
18. `PA3`  `ESP_RX`
19. `PB15` `DHT11_DATA`
20. `PB2`  `LED_STATUS`

如果要加未来扩展，建议再补一组 `J2`：

1. `PB8`
2. `PB9`
3. `ADC1_INx`
4. `ADC1_INy`
5. `PWM1`
6. `PWM2`
7. `3.3V`
8. `5V`
9. `GND`
10. `GND`

## 6. 电源设计建议

### 6.1 输入电源

建议扩展板支持两种供电：

- 主板 USB `5V`
- 外部 `5V` 端子输入

### 6.2 电源树

- `5V` 主输入
  - 给主板
  - 给 USB 外设
  - 给蜂鸣器/继电器等 5V 负载
- `3.3V`
  - 给 OLED
  - 给 ESP-01S
  - 给 DHT11
  - 给 I2C 传感器

### 6.3 保护建议

- USB 或 5V 输入加：
  - 保险丝或自恢复保险丝
  - TVS
  - 反接保护
- 3.3V 供电加：
  - 大电容缓冲 ESP 尖峰电流

## 7. PCB 布局建议

### 7.1 功能区域布局

- 上方：OLED
- 中间：旋钮 + 4 按键
- 一侧：ESP-01S
- 另一侧：传感器与扩展接口
- 底部：电源和主连接器

### 7.2 走线建议

- USB 差分不要经过扩展板乱绕
- ESP 天线区域保持净空
- OLED SPI 线尽量短
- 编码器和按键线远离 ESP 天线与高频电源区
- 电源地做整面铺铜

## 8. 这块扩展板最推荐的版本

如果要做第一版，我建议先出一个 **V1.0 基础交互扩展板**，只做这些：

- OLED
- 编码器
- 4 按键
- ESP-01S 插座
- DHT11 接口
- 蜂鸣器
- 1 颗 RGB 状态灯
- 1 组 I2C 扩展口
- 1 组 ADC 扩展口

这样能兼容你现在的全部主功能，又给后面 UI、联网、传感器扩展留空间，风险也最低。

## 9. 原理图页建议

画原理图时建议拆成 5 页：

1. `Power`
2. `MCU_Board_Connector`
3. `Display_And_Input`
4. `ESP01S_And_Sensor`
5. `Expansion_IO`
